# The World Today — 21 November 2026 in one image

Entry for make.fun bounty **news-image-20261121**: "Sum up 21 November's world news in one image" ($100, 50 places paid, deadline 23 Nov 2026 00:00 UTC / 07:00 WIB).

## What it does
`main.py` (Python 3.13) copies `news.png` to `/output/entry.png`. No network; repeated runs produce identical bytes. Image: 1024×1024 PNG, 226,290 bytes (limit: 1 MiB).

`generate.py` is the deterministic Pillow program that drew `news.png` from the headlines below. It renders the same bytes on every run (sha256 `6eb86578781c3fa07efc3a33349f91bcf5581fbb222222cba888426c647d8c3e`).
